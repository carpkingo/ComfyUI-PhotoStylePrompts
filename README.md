# ComfyUI-PhotoStylePrompts
照片 / 图片风格提示词节点（PhotoStylePrompts）

一个专门为照片或图片风格设计的 ComfyUI 自定义节点：从模板库中选择一个风格，可选地
与一段附加文本合并，输出合并后的完整正向提示词（`prompt`），可接入 CLIP Text Encode
正向，或接入其它文本拼接节点继续组合。

> 说明：`template_name` + `enable_template` + `additional_text` 三个输入，单一 `prompt` 输出，
> 合并固定为「模板在前，附加输入在后」。节点已内置"模板回退读取"机制，并在节点卡**上方**
> 实时预览提示词内容（预览数据从节点自带的 `/psp/templates` 接口读取，显示稳定）。

## 安装位置
本节点已安装到：
```
E:\ComfyUI-aki-v1.6\ComfyUI\custom_nodes\ComfyUI-PhotoStylePrompts
```

## 节点说明
在 ComfyUI 节点面板中，搜索 `PhotoStyle 照片风格提示词`（分类：`提示词/照片风格`）。

### 输入
| 输入 | 说明 |
|------|------|
| `template_name` | 风格模板下拉，内置 42 套照片/图片风格（棚拍 / 胶片 / 审美 / 夜景 / 大师），可自定义添加 |
| `enable_template` | 合并开关，默认开启。**关闭后**模板提示词不参与合并，输出仅等于附加文本 |
| `additional_text` | 附加文本。可手动输入，或点击输入框右侧箭头转换为输入口连接其它文本工具；为空则只输出模板 |

### 输出
| 输出 | 说明 |
|------|------|
| `prompt` | 合并后的完整正向提示词 = 模板风格 + 附加文本（开关关闭时 = 仅附加文本） |

### 提示词查看
节点卡内**不提供实时预览**（已移除，以保证节点固定大小、不受前端扩展影响）。
合并结果直接在节点输出 `prompt`，在工作流中接「展示文本」等文本查看节点即可看到
完整提示词。节点为固定大小的普通节点，不会随内容自动缩放。

### 预览
节点卡上自带实时预览面板，显示当前「模板名 / 合并后正向」，
切换模板或修改附加文本时即时刷新，无需运行。

## 典型接线
```
[PhotoStyle 照片风格提示词]
   ├─ prompt ──► CLIP Text Encode (正面) ──► KSampler
   └─ additional_text ◄── 可选：其它文本工具输出（可留空）

如需进一步拼接/组合文本，可把 prompt 接到 Comfyroll 的「文本联结」等拼接节点。
```

## 自定义添加模板
内置模板均由 **photo-style-library** 风格提示词规范生成——正向提示词是
**一段可叠加到任意主体后的独立中文风格描述**（只描述风格，不绑定主体）。

### 更简便的更新方式（不用改代码）
模板存放在独立的 `photo_style_templates.json` 里，**直接用记事本编辑即可**，
完全不需要修改任何代码：

1. **双击节点目录下的 `编辑模板.bat`** → 自动用记事本打开 `photo_style_templates.json`
2. 在文件里增/改模板（格式见下）
3. 保存
   - **改已有模板的内容** → 回 ComfyUI 直接点 Run（运行）就生效，**不用重启**
   - **新增一个模板名** → 需**重启 ComfyUI**，下拉框里才会出现新名字

### 模板格式
编辑 `photo_style_templates.json`，每个模板是一行，**键是模板名，值是提示词**：
```json
{
  "我的风格": "your style prompt here"
}
```
- 值即该风格的正向风格提示词片段，会与 `additional_text` 合并。
- 模板顺序即下拉框顺序；**别漏掉逗号和引号**（每行键值对之间用逗号，最后一行不带逗号）。
- 兼容旧格式 `"我的风格": {"positive": "...", "negative": "..."}`（节点只读取 `positive`）。

### 推荐风格句法（沿用 photo-style-library）
新增风格时，提示词建议按此结构写，效果最稳定：
```
模拟<介质>摄影，<风格名/胶片型号>风格，<颗粒质感>；<光线类型>，<光线效果>；
色调是<色彩1>+<色彩2>，带有<后期效果>，整体充满<情绪>，且具备自然的<介质>质感。
```
例：`模拟35毫米胶片摄影，柯达Ektar 100胶片模拟风格，极细颗粒；明亮日光，色彩通透浓郁；色调是超高饱和的浓郁红橙与翠绿，整体充满鲜活明艳之感，且具备自然清透的胶片质感。`
> 提示：也可按你自己的习惯改成英文（接英文 CLIP 模型时更通用），节点不做限制。

## 添加模板预览图
节点卡上会显示当前选中模板的预览图（图片在节点下方，选模板即切换）。给模板配预览图规则如下：

1. **图片放进节点目录下的 `previews\` 文件夹**（没有就新建一个）。
2. **文件名 = 模板名**（一字不差、含前缀），例如：
   - `人像-日系清新.png`、`棚拍-艺术肖像.jpg`、`人像-柯达Portra 800.webp`
3. 格式支持 **png / jpg / jpeg / webp**（文件名可不写扩展名，会自动匹配）。
4. 推荐规格：**512×512、正方形 1:1**（节点上以**小格子**显示，看到大概风格即可）。
5. 没有预览图的模板 → 节点上显示"无预览"占位；有图则显示该图。
6. 添加新图片后，浏览器 **Ctrl+F5 硬刷新** 即可看到（若模板名是新增的，需先重启 ComfyUI）。

## 常见问题
- **新增模板后下拉里没有？** 修改 `photo_style_templates.json` 后需重启 ComfyUI。
- **看不到预览面板？** 确认前端扩展已加载：浏览器刷新页面（Ctrl+F5）后重新放置节点。
- **`additional_text` 需要连接时**：点击输入框右侧的转换箭头，把它变成输入口后拖线连接；不连接时可直接手动输入。
